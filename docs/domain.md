# 领域约定

## 核心对象

- 种质材料：包括亲本与中间材料，同一材料可并行参与多个组合
- 育种项目：立项时承载育种目标，并将企业提出的消费与生产需求落成可验证指标
- 需求指标：企业需求在立项阶段形成，带目标值、提出方与立项批次，作为后续试验的验收依据
- 企业参与：按材料阶段登记企业加入与退出，明确企业从哪个阶段参与过决策
- 试验世代：从分离世代到稳定世代逐步推进，跨多年管理
- 试验记录：多年、多点试验数据，支持田间离线采集后回传合并
- 选择淘汰记录：每次选择与淘汰必须保留依据、经办人与时间
- 区域试种：在目标生态区验证口味、采收方式、区域适应性等需求指标
- 品种版本：稳定系到送审版本的版本管理，可反查亲本
- 栽培技术版本：配套栽培技术独立于审定版本单独版本化
- 审定登记：品种审定或登记结果及其状态
- 知识产权：品种权、专利等权利及其归属
- 权利变更：记录权利变更前后状态、依据与时间
- 推广授权：授权链逐笔登记，写明被授权方、区域、繁育用途与有效期
- 种子批次：按批次管理生产、流通与召回
- 农户反馈：关联品种版本与种子批次，跟踪闭环情况

## 已知规则

- 企业需求需要在试验指标中留痕
- 审定与栽培技术分别版本化
- 授权范围不得自动扩张
- 企业需求在立项时转化为可验证指标；未立项的需求不得进入试验世代
- 每次选择与淘汰必须记录依据，并关联经办人与时间
- 授权转让不得超出约定的区域与繁育用途；到期或权利变更后自动失效，不默认续展
- 企业参与按材料阶段登记；中途加入或退出需保留时间、范围与对权利的影响
- 权利变更需保留变更前后状态与依据，并同步影响其后的授权
- 离线采集数据回传后需与对应试验记录合并，并标记采集来源与回传时间
- 批次召回需关联种子批次、品种版本与涉及区域，并核对是否越区
- 农户反馈需关联品种版本与种子批次，处理结果回到推广闭环

## 追溯与落地判定

- 任一上市品种版本必须能反查：亲本材料、各世代试验环境、采用的需求指标及其提出方、完整授权链
- 落地状态不只看审定结果，还要核对配套技术是否发布、授权是否覆盖目标市场、批次是否在控、反馈是否闭环
- 对「已审定但尚未真正落地」的品种显式给出提示，供决策者定位卡点
