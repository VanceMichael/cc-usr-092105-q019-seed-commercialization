# 领域约定

## 核心对象

按品种从材料到推广的生命周期组织。

### 材料与目标

- 种质材料：亲本来源与特征，是反查链的起点
- 育种组合：同一材料可并行参与多个组合
- 育种目标：项目方向
- 企业需求：企业提出的消费和生产需求，立项时转化为可验证指标
- 育种项目：立项载体，绑定目标、需求与指标

### 试验与选择

- 试验世代：多年试验数据按世代连续管理
- 试验记录：支持田间离线采集与事后同步
- 区域试种：不同生态区的适配表现
- 选择淘汰记录：科研人员每次选择与淘汰的依据

### 审定与技术

- 品种版本：审定版本
- 审定登记：与品种版本对应
- 配套栽培技术：与审定分别版本化

### 权利与合作

- 知识产权
- 企业共研参与：企业从材料阶段起的参与记录，中途加入或退出须留痕
- 权利变更：变更前后内容均须记录
- 推广授权：限定区域与繁育用途，不得自动扩张

### 推广与反馈

- 种子批次：可召回
- 推广反馈：农户反馈与批次关联

## 已知规则

- 企业需求需要在试验指标中留痕
- 企业需求必须在立项时形成可验证指标
- 每次选择与淘汰必须保留依据
- 审定与栽培技术分别版本化
- 授权范围不得自动扩张
- 授权转让不得超出约定区域与繁育用途
- 企业中途加入或退出必须留痕并界定权利
- 种子批次可召回并关联农户反馈
- 上市品种可反查亲本、试验环境、采用需求与授权链
- 田间采集支持离线记录与事后同步
- 同一材料可并行参与多个组合
- 已审定未落地的环节必须可识别

## 追溯关系

上市品种须能沿四条链反查：

- 亲本：品种版本 → 育种组合 → 种质材料
- 试验环境：品种版本 → 试验世代与区域试种 → 试验记录
- 采用需求：品种版本 → 育种项目 → 企业需求（立项指标）
- 授权链：品种版本 → 知识产权 → 权利变更 → 推广授权 → 种子批次 → 推广反馈

## 落地缺口

审定登记完成不代表真正落地。以下任一缺失即属"已审定未落地"，须能被决策者识别：

- 配套栽培技术无对应版本
- 无有效推广授权，或授权超出约定区域与繁育用途
- 无种子批次，或批次无法关联召回与农户反馈
- 企业参与阶段无法说清

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
