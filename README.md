# 良种科企协作转化

整理种质材料、新品种试验、企业参与和推广授权资料。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料确认了以下事实：

- 部分品种试种完成后仍面临推广最后一公里
- 行业希望企业从育种材料阶段参与研发
- 品种审定、区域适配、配套技术和知识产权共同影响落地
- 企业需求错位（口味、采收方式、区域条件）往往到试种结束才暴露
- 企业参与阶段、权利变更、批次召回与农户反馈都需要可追溯
- 上市品种需要能反查亲本、试验环境、采用需求与授权链

资料对象覆盖：种质材料、育种项目、需求指标、企业参与、试验世代、试验记录、选择淘汰记录、区域试种、品种版本、栽培技术版本、审定登记、知识产权、权利变更、推广授权、种子批次、农户反馈。样例 `demo-019` 给出一条可反查的品种追溯链，并标注「已审定但授权区域尚未覆盖目标市场」的落地卡点。

## 校验方式

在仓库根目录运行 `python3 -m unittest discover -s tests -v`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整。
